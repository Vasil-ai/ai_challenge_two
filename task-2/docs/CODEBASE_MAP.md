## Repository layout

- `src/main/java/com/events/platform/` — application code (single Maven module)
- `src/main/resources/` — `application.yml`, Flyway SQL under `db/migration/`, SPA shell under `static/` (`index.html`, `assets/app.js`, `app.css`)
- `frontend/` — optional React UI (Vite); not wired into Maven by default
- `config/` — Checkstyle (`checkstyle/checkstyle.xml`), SpotBugs exclude (`spotbugs/exclude.xml`)
- `docs/` — SDD, features, tasks, project-map notes

- `docker-compose.yml` — PostgreSQL 16 only
- `.cursor/` — Cartographer skill and `/cartographer` command

## Runtime and configuration

- **Port:** `server.port` → `${PORT:8080}`
- **Database:** PostgreSQL via `spring.datasource.*`; env vars `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` (defaults align with `docker-compose.yml`: `events` / `5432`)
- **JPA:** `ddl-auto: validate`, `open-in-view: false`, Hibernate timezone UTC
- **Flyway:** enabled; migrations in `src/main/resources/db/migration/`
- **Uploads:** `app.upload-dir` (default `./data/uploads`), served under `/uploads/**` via `WebConfig`
- **Public base URL:** `app.base-url` (`APP_BASE_URL`, default `http://localhost:8080`) — share links / OG
- **Static resources:** `spring.web.resources.add-mappings: false`; `WebConfig` registers `/uploads/**`, then `/**` → classpath `/static/` with SPA fallback to `index.html`
- **Multipart:** max file 10MB, request 12MB

## Architecture

| Area | Role |
|------|------|
| `web/` | REST controllers, MVC share page, DTOs, `RestExceptionHandler`, `SecurityUtils` |
| `service/` | Business logic; `AccessControlService` enforces host/checker-style permissions |
| `repo/` | Spring Data JPA repositories |
| `domain/` | JPA entities and enums |
| `config/` | `SecurityConfig`, `WebConfig`, demo `DataSeed` + `SeedDemoConstants` |

Cross-cutting: validation via Bean Validation on DTOs; API errors as JSON `{ "error": "..." }` from `RestExceptionHandler` and `ApiException`.

## API and interfaces

Base path pattern: **`/api/**`** except where noted. Authenticated routes use session security unless listed as public in `SecurityConfig`.

**Auth (`AuthController`, `/api/auth`)** — `POST /register`, `POST /login`, `POST /logout`

**Current user (`MeApiController`, `/api/me`)** — `GET`, `GET /tickets`, `GET /events`

**Events (`EventApiController`, `/api/events`)** — `GET` list, `GET /{id}`, `POST /{id}/rsvp`, `DELETE /{id}/rsvp`, `PUT /{id}`, `POST /{id}/publish|unpublish|duplicate`, `PATCH /{id}/capacity`

**Hosts (`HostApiController`, `/api/hosts`)** — `POST`, `PATCH /{hostId}`, `GET /by-slug/{slug}`, `POST /{hostId}/events`

**Dashboard (`DashboardApiController`)** — `GET /api/hosts/{hostId}/dashboard`

**Check-in (`CheckInApiController`)** — `/api/events/{eventId}/check-in`: `GET /stats`, `POST`, `POST /undo-last`

**CSV export (`CsvExportApiController`)** — `GET /api/events/{eventId}/export/rsvps.csv`

**Gallery (`GalleryApiController`)** — `GET|POST /api/events/{eventId}/gallery`, `GET /api/hosts/{hostId}/gallery/pending`, `POST /api/gallery/{photoId}/approve`

**Feedback (`FeedbackApiController`)** — `POST /api/events/{eventId}/feedback`

**Invites (`InviteApiController`)** — `POST /api/hosts/{hostId}/invites`, `POST /api/invites/accept`

**Reports (`ReportApiController`)** — `POST /api/reports`, `GET /api/hosts/{hostId}/reports`, `POST /api/reports/{reportId}/resolve`

**Share (HTML)** — `ShareMvcController`: `GET /share/event/{id}`

**Public reads (no auth, per `SecurityConfig`)** — includes `POST /api/auth/register|login`, `POST /api/reports`, `GET /api/events`, `GET /api/events/*`, `GET /api/events/*/gallery`, `GET /api/hosts/**`, `GET /share/**`, `GET /uploads/**`; other `/api/**` requires authentication.

## Data and persistence

**Migrations:** Flyway `V1__schema.sql`, `V2__event_feedback_stars_integer.sql`

**Entities (`domain/`):** `User`, `Host`, `HostMembership`, `Event`, `Ticket`, `RsvpRegistration`, `CheckIn`, `GalleryPhoto`, `EventFeedback`, `InviteLink`, `ContentReport`, plus enums (`EventLifecycle`, `EventVisibility`, `RsvpStatus`, `MembershipRole`, `GalleryPhotoStatus`, report types/statuses).

**Repositories (`repo/`):** `UserRepository`, `HostRepository`, `HostMembershipRepository`, `EventRepository`, `TicketRepository`, `RsvpRegistrationRepository`, `CheckInRepository`, `GalleryPhotoRepository`, `EventFeedbackRepository`, `InviteLinkRepository`, `ContentReportRepository`.

**Demo data:** `DataSeed` runs when `users` is empty (see `README.md`).

## Security and auth

- **Passwords:** BCrypt (`PasswordEncoder` bean)
- **Sessions:** `SessionCreationPolicy.IF_REQUIRED`, `HttpSessionSecurityContextRepository`
- **CSRF:** disabled
- **Unauthenticated API calls:** `401` via `HttpStatusEntryPoint`
- **User loading:** `AuthUserDetailsService` (Spring Security user details)
- **Authorization:** URL-level rules in `SecurityConfig`; finer checks in services via `AccessControlService` / `SecurityUtils`
